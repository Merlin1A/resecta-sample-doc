# search-ground-truth — rebaseline log

Chromium-style discipline: the frozen sidecars (`*.search-gt.json`) change
only through a row here. Every row answers *what changed, why, and which
kind of change it was* — `bug-fix` (the old expectation was wrong),
`intentional` (engine behavior legitimately changed; cells rebaselined), or
`regenerated` (OCR-leg expectations are tool-regenerated by definition —
Vision output is not stable across OS versions and is never hand-edited).

Sidecar provenance: `search-queries.json` (the T3.1 bank) is generated by
`tools/build_search_queries.py`; the frozen GT is emitted by
`tools/search_oracle.py freeze` from an official H3.1 run plus the
adjudication file for that session. Hand-editing a sidecar is a process
violation.
